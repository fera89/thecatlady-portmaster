# Controls (R36S)

The Cat Lady is a **keyboard-only** game (verified on device). The gamepad is
mapped straight to the keys it uses via gptokeyb
([`runtime/controls/thecatlady.gptk`](../runtime/controls/thecatlady.gptk)).
Shown here as **R36S button → what it does in the game**.

| R36S button | In-game action | (key sent) |
|---|---|---|
| D-pad / Left stick ← → | Move (walk between scenes) | Left / Right |
| D-pad / Left stick ↑ | Interact with objects | Up |
| D-pad / Left stick ↓ | Open inventory | Down |
| **A** | Confirm / choose dialogue option | Enter |
| **B** | Save / load menu (back) | Esc |
| **X** | Skip dialogue | Space |
| **Y** | Interact (same as ↑) | Up |
| **L1** | Inventory (same as ↓) | Down |
| **R1** | Interact (same as ↑) | Up |
| **Start** | Save / load menu | Esc |
| **Select** | Save / load menu | Esc |
| **Select + Start** (hold) | Quit to PortMaster | — |

The game's native keys (for reference): Left/Right = move, Up = interact,
Down = inventory, Enter = confirm, Esc = save/load menu, Space = skip dialogue.

No mouse is used — earlier builds mapped A to a mouse click, which did nothing in
this keyboard-driven game; that is fixed.
